Cincinnati Badgers è un sito web statico dedicato a una squadra NBA fittizia, sviluppato interamente in HTML e CSS. Presenta sezioni dedicate alla rosa, staff, classifica, record, trofei e sponsor, oltre a una pagina sull’arena di gioco. Include anche schermate grafiche per accesso e registrazione e un link diretto al sito ufficiale della NBA. Tutti i dati inclusi i giocatori e statistiche, sono stati ottenuti tramite la simulazione di 80 stagioni grazie al videogioco NBA2K23, garantendo un’esperienza realistica e dettagliata.

PER VISUALIZZARE IL SITO (Azione consigliata tramite PC):
<br></br>
-Scaricare la zip del file ed estrarla.
<br></br>
-Aprire la cartella del proetto tramite un editor (Es. Visual Studio Code).
<br></br>
-Posizionarsi sul file index e con tatso destro cercare la voce "Open with live server".
<br></br>
  -Se questa voce non è presente è necessario installare l'estensione "live server".
<br></br>
-Il sito si aprirà in automatico sulla vostra pagina web.
